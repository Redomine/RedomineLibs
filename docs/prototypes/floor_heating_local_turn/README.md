# LocalTurnDiagnostic v0.1

`local_turn_generator.py` — отдельный эксперимент, **не** замена принятому генератору. Он смещает реальную границу один раз, от текущего конца идёт прямо до ближайшей границы или ранее уложенного участка и в этой точке выбирает поворот. Он не строит заранее прямоугольные или контурные кольца. Последний выход к свободному концу второй трубы пока выполняется диагностическим ортогональным соединением **без** доказанной допустимости; маршруты не прошли валидацию.

Вывод для семи контуров предназначен только для визуального разбора ошибок. Красные линии не следует использовать как проектное решение.

Версия `v0.1` сохранена отдельно от принятого генератора. Проверка геометрии, отступов, шага, покрытия и пересечений не завершена. Данные модели и построенные маршруты намеренно не включены в публичный репозиторий.
